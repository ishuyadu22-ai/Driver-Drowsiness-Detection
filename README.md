# Personalized Mobile-Based Driver Drowsiness Detection System

## Project Overview

This project aims to detect driver drowsiness using computer vision and machine learning. It is designed to identify signs of fatigue through facial features and eye movements.

## Objectives

* Detect the driver's face and eyes.
* Monitor eye closure and blinking patterns.
* Identify possible signs of drowsiness.
* Generate an alert when drowsiness is detected.
* Explore personalization based on the driver's normal blinking patterns.
